# インタビュー発話のマスキング

## 作業手順

1. Webページを開き、「ファイルを選択」をクリックして `interview.csv` を選びます。
2. 作業を始める行番号を入力して、「アノテーション開始」を押します。行番号は1から数えます。
3. 発話中の隠したい箇所をドラッグして選択します。
4. 置き換え後の文字列を入力し、必要であれば理由も入力して、注釈を保存します。
5. 同じ発話にほかの対象箇所があれば、同じ手順で注釈を追加します。
6. 「前へ」「次へ」、またはキーボードの左右キーで発話を移動し、作業を続けます。既存の注釈はクリックして編集できます。
7. 作業が終わったら、出力形式とファイル名を確認し、画面右上の「保存」を押します。

開始行より前には移動できません。保存すると、開始行から作業した範囲の注釈がファイルとしてダウンロードされます。出力形式の既定値はJSON、ファイル名の既定値は `annotation_result.json` です。必要に応じてYAMLや別のファイル名に変更できます。

## お願い

マスキングによる情報損失をできるだけ抑えられるよう、可能な範囲で単語単位に、マスキング箇所を最小限にしていただけると助かります。

## CSVについて

- アノテーション対象のファイル名は `interview.csv` です。
- 1つのCSVレコードを1つの発話として扱い、各レコードの1列目を発話本文として読み込みます。
- 空のレコードは読み飛ばされます。
- 先頭行にヘッダーがある場合も発話として扱われます。ヘッダーを対象にしない場合は、ヘッダーを含めずに用意してください。

## データの保存

CSVはブラウザ内で読み込まれ、アノテーション対象や結果をサーバーへ送信する処理はありません。結果は「保存」を押したときにダウンロードされます。作業中の注釈は自動保存されないため、ページを閉じる前に保存してください。
